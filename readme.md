# Syntezator Arduino

To repozytorium zawiera kod który został napisany w ramach realizacji pracy inżynierskiej i w takiej formie pozostanie. Można więc przeczytać pracę inżynierską i śledzić ją z tym kodem. W tym kodzie mogą znajdować się bugi więc zalecam ostrożność podczas uruchamiania. Stan kodu jest taki jak opisano w pracy inżynierskiej, zakończono na próbie implementacji systemu RTOS który napędzałby cały projekt. Polecam więc przeczytać tą [pracę inżynierską](Praca%20inżynierska%20—%20Paweł%20Sokół.pdf) w której dokładnie opisano napotkane problemy podczas implementacji wirtualnego polifonicznego syntezatora dźwiękowego na mikrokontroler AVR (ATmega328P). Praca inżynierska również szczegółowo wyjaśnia zasadę działania takiego syntezatora, oraz jak ten kod funkcjonuje.

Projekt jest nadal rozwijany, ale w osobnym repozytorium [asmSynth](https://github.com/ezasm/asmsynth). 
Na potrzeby tego projektu został opracowany także dedykowany system RTOS, zgodnie ze specyfikacją podaną w pracy inżynierskiej, który można znaleźć w repozytorium [ObjectiveRTOS](https://github.com/ezasm/ObjectiveRTOS).

Można znaleźć mnie także na kanale youtube *[@sezam](https://www.youtube.com/@sezam9201)* gdzie zamieszczone są nagrania demonstrujące działanie tego projektu.
